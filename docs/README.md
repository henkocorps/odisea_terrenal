# Documentación Legal y Evidencias - Henko Corps

Este directorio está diseñado para estructurar y salvaguardar la documentación legal, pruebas y evidencias relacionadas con las operaciones y defensas de Henko Corps.

## Estructura

*   `/legal`: Documentación constitutiva, acuerdos internacionales y representación legal (Suiza, Noruega, Islas Caimán).
*   `/evidences`: Repositorio seguro para almacenar pruebas, actas, atestados policiales y resoluciones administrativas vinculadas a procedimientos de defensa o whistleblowing.

*Nota: Asegúrese de no subir información sensible sin el cifrado adecuado si este repositorio es público.*
